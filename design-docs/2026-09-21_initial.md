# Yomiagen 初期デザイン & コンセプト

長いブログ記事や調査レポートを音声化して、運転中やジムのトレーニング中など、手がふさがるアクティビティの最中に聞いて消化したい。

HTMLや生の調査レポートといったデータを読み上げに適した形に変換し、必要であれば抑揚や読みがなの付与をおこなってTTSで音声化する。
音声はいくつかプリセットを用意しておき、そのうちのどれかを自動あるいは手動で選ぶ。

もっとも自動的な利用方法では、生データに対してコマンドを実行するとすべてのパイプラインが動いて音声データが作成される。
もっと細かく、中間生成物をレビューしながら生成を進めるパイプライン制御もできる。

処理コストはトラッキングできるようにする。

## サポート言語

日本語と英語の両方をサポートしたい。さらに、英語が多分に混ざる日本語文書（ソフトウェアや数学系の技術文書）もサポートする。

## 技術スタック（案）

- データ変換処理: OpenAI
- TTS: VOICEVOX / AivisSpeech / Google Cloud TTS
  - 複数バックエンドを試せる構成だと良い
- 主なプログラミング言語: Go
  - jsonはjsonv2を使う。
  - ロガーはslogを使う。
  - 可能限り外部依存を入れない。
- Webフロントエンドを作る場合: Next.js + tailwind css
- タスクランナー: Just
